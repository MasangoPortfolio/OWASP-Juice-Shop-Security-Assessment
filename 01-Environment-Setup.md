# 01 - Environment Setup

## Target

OWASP Juice Shop `20.2.0` hosted locally in a controlled environment for security testing.
The application is intentionally vulnerable and is used as a local security testing target.

**Target Address:** `http://127.0.0.1:3000`

## Installation Method

**Source:** [OWASP Juice Shop Releases](https://github.com/juice-shop/juice-shop/releases/)

**Juice Shop version:** `20.2.0`

**Package:** `juice-shop-20.2.0_node22_win32_x64.zip`

The Windows x64 packaged release was downloaded and extracted locally.

## Tools

| Tool                         | Purpose                                                  |
| ---------------------------- | -------------------------------------------------------- |
| OWASP Juice Shop             | Deliberately vulnerable target used for security testing |
| Burp Suite Community Edition | HTTP interception, inspection and request manipulation   |
| Microsoft Edge               | Web application interaction                              |
| Browser Developer Tools      | Client-side inspection and debugging                     |
| Git / GitHub                 | Version control and documentation                        |

## Setup Procedure

1. Downloaded the official Juice Shop `20.2.0` Windows x64 release.
2. Extracted the application locally.
3. Started Juice Shop using Node.js and npm.cmd.
4. Confirmed that the application was accessible through Microsoft Edge.
5. Installed and launched Burp Suite Community Edition.
6. Configured the browser to use Burp Suite as an HTTP proxy.
7. Confirmed that Juice Shop requests appeared in Burp Suite HTTP history.
8. Captured a request and sent it to Burp Repeater.
9. Confirmed that the captured request could be resent successfully.
10. Created a Git repository for the assessment documentation.
